# Release candidate notes

HosePipe **0.7.1-rc.3** is a release candidate at [hosepipe.freestar.network](https://hosepipe.freestar.network). It is pre-stable — expect occasional rough edges before the stable release.

## What works well

- Live talkgroup monitoring and selective listening in the browser
- Favorites, country filter, search, and recent activity
- Expandable Speech clarity on desktop; Clarity On/Off on mobile
- Live audio level (VU) meters while listening
- Mobile listening bar for volume, clarity, and stop on small screens
- Reliable listening across Wi‑Fi and mobile network handoffs (soft reconnect)
- Desktop Chrome/Edge/Firefox

## Known limitations

- Brief noise or hiss between transmissions on some talkgroups — try **Speech clarity** in the listening desk
- Mobile background audio is not guaranteed (OS/browser policy)
- Listener counts reflect HosePipe sessions on that instance, not all external listeners
- Speech clarity fine-tuning is desktop-only; mobile uses the shared On/Off profile

## This repo

Product documentation and feedback live here — not a self-hosting or deployment guide. Source and operator docs remain in the private engineering repository.
